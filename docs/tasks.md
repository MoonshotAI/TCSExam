# Task catalogue

[English](tasks.md) | [简体中文](tasks.zh-CN.md)

This catalogue links task instructions in Full and marks the Lite selection.
It is for users choosing tasks and reading their requirements.

Theorem, construction and open-conjecture instructions are shared across suites
and Solver protocols. All thirty Solver tasks have separate online and offline
folders.

All listed tasks belong to Full. Lite selects five tasks per track. Prepare the
selected images and run `tcsexam doctor` before evaluation.
Full/Lite membership is independent of the Solver protocol.
