Research outcomes

These constructions improve on the best previously known results, to the best of our knowledge.

629 → 630 edges

Kimi K3 · Verified construction

More edges, no short cycles

Kimi K3 constructed a 630-edge graph, improving on the 629-edge construction of Goedgebeur et al.

Connect 124 vertices with as many edges as possible, while forbidding triangles and four-edge cycles.

Each extra edge makes the cycle restrictions harder to satisfy. This construction raises the lower bound on the maximum possible edge count for 124 vertices, a concrete advance in extremal graph theory.

Distance 5 → 6

GPT-6 Astra · Quantum error correction

A stronger quantum code

Astra’s code detects every damaging error affecting up to five qubits, improving the reference code’s limit of four.

Protect 7 logical qubits using 25 physical qubits.

Stronger error detection with the same number of qubits.

# After Install and Configure, in the same shell:
tcsexam source-inputs
tcsexam build --suite lite --solver-protocol offline \
  --output build/lite-offline-images.json
tcsexam doctor --suite lite --solver-protocol offline \
  --agent kimi-code --artifacts build/lite-offline-images.json \
  --output build/lite-offline-readiness.json
# Resolve doctor blockers before starting model API usage.
tcsexam run --suite lite --solver-protocol offline \
  --agent kimi-code --artifacts build/lite-offline-images.json \
  --attempts 1 --concurrency 1 \
  --output build/lite-offline-job.json
