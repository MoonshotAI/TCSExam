Graph coloring

Color adjacent vertices differently using as few colors as possible.

The research question

In the graph coloring problem you are given an undirected graph and must assign a color to every vertex so that adjacent vertices get different colors, using as few colors as possible. The smallest possible number of colors is the chromatic number χ(G). Graph coloring is NP-hard, and it is hard even to approximate: unless NP = ZPP, no polynomial-time algorithm approximates χ(G) within a factor n^(1−ε) for any ε > 0.
