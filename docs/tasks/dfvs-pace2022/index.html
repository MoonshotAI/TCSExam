Directed feedback vertex set

Delete as few vertices as possible so that no directed cycle remains.

The research question

A directed feedback vertex set (DFVS) of a directed graph is a set of vertices whose removal leaves the graph acyclic: delete the set, and no directed cycle survives. Finding a minimum DFVS is NP-hard (it is one of Karp's 21 NP-complete problems) and shows up in deadlock breaking, program analysis, and circuit design.
