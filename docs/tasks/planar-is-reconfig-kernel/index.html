Independent-set reconfiguration

Prove that the stated graph instances admit an equivalent reconfiguration instance with linearly many vertices in k.

The research question

The theorem comes from graph reconfiguration. An independent set in a graph is a set of vertices no two of which are adjacent; picture a token on each of its vertices. In the token jumping (TJ) model, one step removes a single token from its vertex and places it on any other vertex, provided the result is again an independent set. The ISR-TJ problem asks, given a graph G and two size-k independent sets Is, It, whether a sequence of such jumps transforms Is into It. A kernel is a compression of the instance to an equivalent one whose size is bounded by a function of k alone. Write X := Is ∪ It for the key vertices; the vertices outside X are grouped into projection classes by their neighborhood inside X, and N2/N3 count the nonempty classes on exactly 2, respectively at least 3, key vertices. The theorem states:

Fix 1 ≤ r and 1 ≤ k. Let G be a finite simple graph with no K_{3,r} minor, given together with a proper coloring with max{r,6300} + 3 colors and with the bound N2(G) + N3(G) ≤ 2^{5r+13}·(r+3)^{2r+5}·k. Let Is, It be independent sets of size k. Then there is a vertex set W ⊇ X with |W| ≤ K(r)·k, where K(r) = 2 + q + (r−1)·B + q·(B·(4r−1)+1) for q = max{r,6300}+3 and B = 2^{5r+13}·(r+3)^{2r+5}, such that Is reconfigures into It under token jumping if and only if it does so using only vertices of W.
