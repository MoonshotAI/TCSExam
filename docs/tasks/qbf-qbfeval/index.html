Quantified Boolean formulas

Decide whether quantified Boolean formulas are true or false and supply a machine-checkable proof certificate for every answer.

Task results ↓

Mathematical setting
∀x ∃y: (x∨y)∧(¬x∨¬y)\forall x\,\exists y:\ (x\lor y)\land(\neg x\lor\neg y)∀x∃y: (x∨y)∧(¬x∨¬y)

The research question

QBF (quantified Boolean formula) extends SAT with quantifiers: a formula in prenex CNF like ∀x ∃y: (x ∨ y) ∧ (¬x ∨ ¬y) is a two-player game — the universal player picks x, the existential player answers with y, and the formula is true if the existential player has a winning strategy for every universal move. Deciding QBF is the canonical PSPACE-complete problem.

Both TRUE and FALSE answers must include the task’s Q-resolution proof certificate. The checker verifies it through the qrp2rup and drat-trim chain; a correct status without a verified certificate receives no solved credit.
