Proximity gaps for algebraic codes

Prove the mutual correlated agreement guarantee for subspace-design codes under the supplied hypotheses.

The research question

The theorem comes from coding theory. A code has a proximity gap if, along a low-degree parametric curve of words, either almost no curve points are close to the code or all of them are; the formal statement is about mutual correlated agreement (MCA) for subspace-design codes (codes whose low-dimensional subspaces lose dimension quickly when pinned at coordinates). The theorem states:

Every τ-subspace-design code has mutual correlated agreement with proximity 1 − τ((ℓ+1)t) − 3/(2t), error t·ℓ·(ℓ+1)·(m(1−τ((ℓ+1)t)) + 2t²)/|F|, and slack 1/m (for 2 ≤ m ≤ 4t, under the stated field-size and boundary hypotheses).

Two ingredients are given as hypotheses: a pruning guarantee (PruningGuarantee) and a list-size bound (ListSizeBound), both packaged as hypothesis-level definitions in the file.
