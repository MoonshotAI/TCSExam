Set cover

Select a minimum-cost collection of subsets whose union covers the universe.

The research question

The set covering problem (SCP): you are given m rows and n columns. Every column j covers a fixed subset of the rows and costs an integer c_j > 0. Choose a set of columns so that every row is covered by at least one chosen column, at minimum total cost.

SCP is NP-hard. For every fixed ε in (0,1), approximating set cover within (1−ε) ln m is NP-hard, where m is the number of rows to cover.
