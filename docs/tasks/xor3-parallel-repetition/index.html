Parallel repetition of XOR games

Prove exponential decay under parallel repetition of the specified three-player XOR games.

Task results ↓

Mathematical setting
val⁡(G⊗n)≤2−cn\operatorname{val}(G^{\otimes n})\le2^{-cn}val(G⊗n)≤2−cn

The research question

The theorem comes from game theory. A 3-XOR game G is given by a probability distribution μ over question triples (x, y, z) and a target t(x, y, z) in a finite abelian group A: the verifier samples (x, y, z) ~ μ, collects answers f(x), g(y), h(z) ∈ A from the three players, and accepts iff f(x) + g(y) + h(z) = t(x, y, z). The value val(G) is the best acceptance probability over all strategies. In the n-fold parallel repetition the verifier samples n independent challenges and the players must win all of them. An embedding of μ into an abelian group is a triple of maps σ, γ, ϕ with σ(x) + γ(y) + ϕ(z) = 0 on the support of μ; μ has no ℤ-embeddings if every embedding into (ℤ, +) is constant in each coordinate. The theorem is stated conditionally on a packaged additive-combinatorics input FreimanAssumption (part of the definition layer), and states:

If val(G) < 1 and μ has no ℤ-embeddings, then val(G^⊗n) ≤ 2^{−cn} for some c > 0 (depending on the game) and all n ≥ 1.
