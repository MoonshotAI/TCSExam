The research question

Syntax-guided synthesis (SyGuS) is the problem of automatically writing a program: given a logical specification over unknown functions ("the output must satisfy these constraints for all inputs") and, optionally, a grammar restricting the shape of candidate programs, find a function definition that satisfies the specification. It is the standard formulation of program synthesis. Benchmarks in this area span several families: conditional linear integer arithmetic (CLIA), bit-vector programming-by-examples (PBE_BV), string transformations from input/output examples (PBE_SLIA), invariant synthesis (Inv), and a general family.
