Subtraction in arithmetic formulas

Prove that the specified graph polynomials have small arithmetic formulas but require exponential monotone formulas.

Task results ↓

Mathematical setting
{+,×,−}versus{+,×}\{+,\times,-\}\qquad\text{versus}\qquad\{+,\times\}{+,×,−}versus{+,×}

The research question

The theorem comes from arithmetic complexity. An arithmetic formula computes a multivariate polynomial using +, −, × gates; it is monotone if it has no subtraction gate and all its constants are non-negative. From any n-vertex graph G one builds the graph polynomial P_G = Σ_{a ∈ {0,1}ⁿ} (e(G[supp a]) − 1)² · ∏ᵢ x_{i,aᵢ} on the variable set {x_{i,0}, x_{i,1}} (all coefficients non-negative). The theorem states: for every degree d ≥ 2 there are a constant c > 0 and a threshold N₀ such that for all n ≥ N₀ and every n-vertex d-regular spectral expander G (second largest eigenvalue in absolute value of the adjacency matrix at most d^{3/4}), the graph polynomial P_G is computed by an explicit arithmetic formula of size at most 35·(e(G)+1)²·n, but every monotone arithmetic formula computing P_G has size at least 2^{c·n}. A random-matching existence lemma is given as the hypothesis expanderMatchingProp (with per-degree constants).
