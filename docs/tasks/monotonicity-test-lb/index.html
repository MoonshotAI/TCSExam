The cost of testing monotonicity

Prove the stated lower bound on adaptive queries needed to test monotonicity of Boolean functions.

Task results ↓

Mathematical setting
x≤y ⟹ f(x)≤f(y)x\le y\ \Longrightarrow\ f(x)\le f(y)x≤y ⟹ f(x)≤f(y)

The research question

The theorem comes from property testing. A Boolean function f : {0,1}ⁿ → {0,1} is monotone if flipping a coordinate of an input from 0 to 1 can never flip the value from 1 to 0, and it is ε-far from monotone if every monotone function disagrees with it on at least an ε fraction of the cube. A monotonicity tester queries values of an unknown f and must tell the two cases apart; the question is how many queries an adaptive algorithm needs. The theorem states: for every integer constant ℓ ≥ 1 there are a testing distance ε > 0 and an error δ > 0 such that for all sufficiently large m (with n = m²) no randomized adaptive algorithm whose deterministic members all have depth at most q = n^{1/2−1/(4ℓ+2)}/log₂ n can both accept the yes distribution Dyes with probability at least 1 − δ and, jointly under the no distribution Dno, accept an ε-far-from-monotone function with probability at most δ. The two distributions and the stronger oracle they are queried through are defined in the file.
