Folded Reed–Solomon list decoding

Prove the stated list-decoding guarantee for folded Reed–Solomon codes.

Task results ↓

Mathematical setting
(f(αi),f(γαi),…,f(γs−1αi))\bigl(f(\alpha_i),f(\gamma\alpha_i),\ldots,f(\gamma^{s-1}\alpha_i)\bigr)(f(αi​),f(γαi​),…,f(γs−1αi​))

The research question

The theorem comes from coding theory. A folded Reed–Solomon code packs the evaluations of a low-degree polynomial f at consecutive powers of a multiplicative generator γ into blocks: the i-th symbol of the encoding is the block f(αᵢ), f(γαᵢ), …, f(γ^{s−1}αᵢ). A code is list-decodable with radius ρ and list size L if no Hamming ball of radius ρ contains more than L codewords. The theorem states:

For ε > 0, 1 ≤ k < N, s ∣ N, n = N / s, q > n, rate R = k/N, and any L > (1−R−ε)/ε and s > L·(L−1)·R/(εL−(1−R−ε)) + L − 1, the folded Reed–Solomon code FRS^{(s,γ)}_{n,k}(α) at appropriate evaluation points is (1 − R − ε, L) list-decodable.
