Compounding resources

Write a solver that chooses affordable machine upgrades to maximize final production.

Task results ↓

The research question

This is a deterministic single-player production game with N = 10 machine types, each present at L = 4 levels. The game lasts T = 500 turns and starts with K = 1 apple.

For each level and type, B[level][id] is the number of machines owned and starts at one. P[level][id] is the number of upgrades bought and starts at zero. The input supplies a production multiplier A[id] and a base upgrade cost C[level][id].

Each turn has two phases:

  1. Action. Buy at most one upgrade, or do nothing. An upgrade of type id at level level costs C[level][id] * (P[level][id] + 1) apples. It must be affordable at that moment; buying it deducts the cost and increments P[level][id] by one.
  2. Production. Process levels in order from zero to three. At level zero, apples += A[id] * B[0][id] * P[0][id]. At each higher level l, B[l-1][id] += B[l][id] * P[l][id]. Machines produced during this phase start contributing from the following turn.

The raw score is

raw = round(100000 * log2(final_apples)).

Higher final apple counts are better. An unaffordable purchase or a nonpositive final apple count scores zero. The task’s scorer uses signed 64-bit arithmetic with wrap-around.
