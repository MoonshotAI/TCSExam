Vertex cover (exact)

Return a valid vertex cover no larger than the task’s reference size on as many instances as possible.

Task results ↓

The research question

A vertex cover of an undirected graph is a set of vertices touching every edge: for each edge, at least one endpoint belongs to the set. Finding a smallest vertex cover is NP-hard.

This task uses the exact edition’s scoring rule. An instance counts as solved only when the solver produces a valid cover whose size is at most its fixed reference value K_G. A valid cover with one vertex too many receives the same solved credit as no output.

For most judged instances, the reference is a proven optimum; for the remaining instances it is a best-known upper bound. A valid cover smaller than the reference also counts as solved. The goal is to solve as many instances as possible within their individual time limits.
