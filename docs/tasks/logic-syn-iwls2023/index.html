Logic synthesis

Build an AND-inverter circuit that matches the given truth table using as few AND gates as possible.

Task results ↓

Mathematical setting
fcircuit=ftablef_{\mathrm{circuit}}=f_{\mathrm{table}}fcircuit​=ftable​

The research question

A completely specified Boolean function with n inputs and m outputs is given as a truth table. Your job: synthesize a combinational circuit that computes exactly this function, built from two-input AND gates and inverters (an and-inverter graph, AIG), using as few AND gates as possible. Inverters are free.

This is a practical circuit-minimization task in logic synthesis: find a small AND-inverter graph for an explicitly given truth table.
