The integer round-up gap

Prove or refute that one extra bin beyond the rounded configuration relaxation always suffices.

After this task was selected, OpenAI reported counterexamples to this conjecture and accompanying Lean formalizations.

Task results ↓

Mathematical setting
OPT⁡(I)≤⌈LP⁡(I)⌉+1\operatorname{OPT}(I)\le\lceil\operatorname{LP}(I)\rceil+1OPT(I)≤⌈LP(I)⌉+1

The research question

A bin pattern is a combination of items that fits into one bin. The configuration linear program allows fractional amounts of these patterns, giving a lower bound on the integer number of bins.

The modified integer round-up property conjectures that rounding the fractional optimum upward and adding one extra bin always suffices. Its quantifier ranges over every valid instance.

Current status: OpenAI has published a counterexample and Lean proof in its public mathematics release. The benchmark retains the statement fixed for evaluation. DeepSeek V4.1 Flash 1017 retrieved and adapted that public proof to the task’s fixed definitions in the evaluated runs.
