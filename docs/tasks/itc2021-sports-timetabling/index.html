Sports timetabling

Construct a double round-robin schedule satisfying hard rules and minimizing soft penalties.

Task results ↓

Mathematical setting

The research question

In sports timetabling you are given an even number of teams and must build a compact double round-robin schedule — every pair of teams plays twice (once at each home venue), every team plays exactly one game in every round. On top of this backbone, the instance imposes constraints from nine classes — capacity (CA1–CA4: how many home/away games given teams play in given slot sets, against given opponent groups, in any window of consecutive slots), game (GA1: how many listed games a slot set hosts), breaks (BR1/BR2: home streaks / away streaks), fairness (FA2: differences between teams’ cumulative home-game counts at specified rounds) and separation (SE1: minimum distance between the two legs of a pair). Some are marked HARD in the instance; the rest are soft, and each violated soft constraint adds its penalty to the objective. The goal: minimize the total soft penalty while keeping every hard constraint satisfied. A schedule with any hard violation is worthless (that instance scores 0).

For phased instances (gameMode=P), each half of the season must itself be a complete single round robin: every pair meets once in each half.

Sports timetabling is NP-hard.
