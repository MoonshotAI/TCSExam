Dominating set

Find a small set of vertices that reaches every other vertex through an edge.

Task results ↓

Mathematical setting
V=D∪N(D)V=D\cup N(D)V=D∪N(D)

The research question

A dominating set of an undirected graph is a set of vertices D such that every vertex outside D has at least one neighbor in D. The goal: find a dominating set as small as possible. The decision version is NP-complete, and getting a good approximation in polynomial time is believed to be hard, so in practice heuristic solvers matter.
