Hitting set

Choose as few vertices as possible while meeting every set in a hypergraph.

The research question

A hitting set of a set family (a hypergraph) is a set of vertices H such that every given set contains at least one vertex of H. The goal: find a hitting set as small as possible. This is the hypergraph generalization of vertex cover, and it is equivalent to set cover by duality (swap the roles of vertices and sets). The decision version is one of Karp's 21 NP-complete problems; parameterized by the solution size it is W[2]-complete; and for a family of m sets, the greedy method gives an H_m approximation, where H_m ≤ 1 + ln m. For every fixed ε in (0,1), obtaining a (1−ε) ln m approximation is NP-hard. In practice, heuristic solvers matter.
