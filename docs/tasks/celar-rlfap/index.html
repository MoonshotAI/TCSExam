Radio frequency assignment

Assign allowed frequencies to radio links while satisfying hard constraints and minimizing weighted interference penalties.

The research question

In the radio link frequency assignment problem, a set of radio links must each be assigned one transmit frequency. Every link has its own allowed set of discrete frequencies, and interference between links is modelled by two kinds of binary constraints on the assigned frequencies f[x], f[y]:

  • hard equality constraints |f[x] − f[y]| = k — must hold exactly (they typically pair a link with a frequency-shifted duplicate);
  • soft separation constraints |f[x] − f[y]| > k — each violated one costs costs[w], where w is the constraint's weight class; the objective is the total weighted violation, smaller is better.

This weighted partial constraint satisfaction problem is NP-hard.
