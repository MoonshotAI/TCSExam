Bin packing

Pack every item into a capacity-limited bin while minimizing the number of bins.

Task results ↓

Mathematical setting
∑i∈Bjwi≤C\sum_{i\in B_j}w_i\le Ci∈Bj​∑​wi​≤C

The research question

The one-dimensional bin packing problem (BPP): you are given n items with integer weights w_1 .. w_n and an unlimited supply of identical bins of integer capacity C. Pack every item into bins so that no bin's total weight exceeds C, using as few bins as possible. BPP is NP-hard — it is NP-complete to decide whether two bins suffice.
