Limits of one-query synthesis

Prove the expected distinguishing-advantage bound for the stated one-query adversary model.

The research question

The theorem comes from quantum query complexity. A one-query adversary is a triple (M, V, Pj): an isometry V : ℂ^N → ℂ^M and a projection Pj on ℂ^M. It prepares a binary phase state |ψ_h⟩ = (1/√N) Σ_x h(x)|x⟩ for a Boolean function h : [N] → {±1}, applies V, makes a single oracle query (the oracle f : [M] → {±1} acts as the diagonal sign matrix O_f), and measures with Pj; its acceptance probability is p_A(h|f) = Re ⟨Vψ_h, O_f Pj O_f Vψ_h⟩. For a function family R : [K] × [N] → {±1}, the distinguishing advantage is Δ_A(R) = max_f [ E_k p_A(R_k|f) − E_h p_A(h|f) ]. The theorem states:

There is an absolute constant C > 0 such that for every one-query adversary (M, V, Pj) with 1 ≤ M, 1 ≤ K, and all isometry weights positive, the expected distinguishing advantage over a uniformly random function family is at most C·√(ln M / K).
