Three-query locally correctable codes

Prove an exponential block-length lower bound for linear three-query locally correctable codes.

Task results ↓

Mathematical setting

The research question

The theorem comes from coding theory. A linear 3-query locally correctable code in normal form is a systematic linear code ℒ : F₂ᵏ → F₂ⁿ together with, for every coordinate u, a 3-uniform hypergraph matching H u of d0 edges such that x_u = Σ_{v ∈ C} x_v (over F₂) for every edge C ∈ H u and every codeword x. The theorem states: there is an absolute constant C > 0 such that every such code with d0 ≥ δn satisfies k ≤ C·(log₂ n)⁸/δ², i.e. n ≥ 2^{(δ²k/C)^{1/8}}. A linear 2-LDC lower bound is given as a hypothesis.
