Two-query PCP soundness

Prove the stated bound on maximal zoom-out function pairs in the inner PCP analysis.

Task results ↓

Mathematical setting
Q⊆L⊆WQ\subseteq L\subseteq WQ⊆L⊆W

The research question

The theorem comes from PCP combinatorics. An inner PCP encodes a linear function f : F_q^n → F_q by its restrictions to subspaces, and the soundness analysis works with zoom-out function pairs (W, g): a subspace W and a linear g : W → F_q agreeing with the encoding table on a noticeable fraction of the 2ℓ-dimensional subspaces L with Q ⊆ L ⊆ W. A pair is (C, ζ)-maximal if no proper extension reaches agreement ζ·C. The theorem states: under two packaged hypotheses (a many-zoomouts refinement and a generic-family sampling bound), for every δ > 0 there is ℓ₀ such that for all ℓ ≥ ℓ₀ and all ambient dimensions n ≥ 2^{100}·q^ℓ, for every table T on F_q^n, every subspace Q of dimension r₁ ≤ 10/δ, and every C ≥ q^{-2(1-δ³)ℓ}, the number of (C, 1/5)-maximal zoom-out function pairs with respect to T on Q of ambient codimension at most 10/δ is at most (160/δ)·C^{-2}·q^{100(t-1)!(10/δ)²ℓ/ξ} (with ξ = δ⁵ and t = ⌈2^{2+10/δ₂}⌉!, δ₂ = ξ/100).
