Maximum clique

Find a largest set of pairwise adjacent vertices in a graph.

The research question

In the maximum clique problem you are given an undirected graph and must find the largest set of vertices that are pairwise adjacent — a clique. The size of a largest clique is denoted ω(G). Maximum clique is NP-hard, and it is hard even to approximate: unless NP = ZPP, no polynomial-time algorithm approximates ω(G) within a factor n^(1−ε) for any ε > 0.
