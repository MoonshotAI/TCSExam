Machine reassignment

Reassign processes to machines while respecting resource and service constraints and reducing total cost.

Task results ↓

Mathematical setting
process⟼machine\text{process}\longmapsto\text{machine}process⟼machine

The research question

In the machine reassignment problem a set of processes runs on a set of machines. Each process consumes an amount of several resources (CPU, RAM, ...), and each machine has a finite capacity per resource. Every process starts on an initial machine. Your job: produce a new assignment of processes to machines that lowers the total cost while respecting every hard constraint.

Hard constraints (all checked by the reference checker):

  • Capacity — per machine and resource, total usage must not exceed capacity. Transient usage: a process moved away from its initial machine still occupies its transient resources on the origin machine (during the reassignment both machines are charged). This ghost usage matters for the capacity check only; the objective's load/balance terms below use current usage only.
  • Conflict — two processes of the same service cannot share a machine.
  • Spread — the processes of a service must occupy at least spreadMin distinct locations.
  • Dependency — if service A depends on service B, every process of A must run in a neighborhood where at least one process of B runs.

Objective (weighted sum, all weights given in the model file):

  • load cost — per machine/resource: weight_r * max(0, usage - safetyCapacity);
  • balance cost — per balance triple (r1, r2, target, weight) and machine: weight * max(0, target * remaining(r1) - remaining(r2));
  • process move cost — per moved process: moveCost_p * weightPMC;
  • service move cost — weightSMC * (max over services of the number of moved processes in that service);
  • machine move cost — per moved process, a machine-to-machine cost from a full matrix, times weightMMC.
