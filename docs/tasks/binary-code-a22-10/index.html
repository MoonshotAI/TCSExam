Binary codes of length 22

Prove lower or upper bounds on the size of a length-22 binary code with minimum Hamming distance ten.

Task results ↓

Mathematical setting
C⊆{0,1}22,dmin⁡(C)≥10C\subseteq\{0,1\}^{22},\qquad d_{\min}(C)\ge10C⊆{0,1}22,dmin​(C)≥10

The research question

A binary code is a set of words of a fixed length. Here every word has 22 bits, and each pair of distinct words must differ in at least ten positions. The quantity A(22,10) is the largest possible size of such a code.

The task accepts either direction: an explicit code with verified pairwise distances gives a lower bound on A(22,10), while a proof limiting the size of every valid code gives an upper bound. A construction is valid only when every distinct pair satisfies the distance requirement. The illustration uses shortened rows to explain that check.

Explore error correction

Astra also supplied this 64-word code. Every word has 22 bits, and any two differ in at least 10 positions. Recovery is guaranteed for every pattern of up to four flips.

Select a codeword and flip its bits to inspect recovery. This construction attains the existing lower bound of 64; the improved upper bound of 82 comes from a separate proof.
