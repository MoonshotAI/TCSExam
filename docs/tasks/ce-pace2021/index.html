Cluster editing

Add or delete as few edges as possible to turn a graph into disjoint cliques.

Task results ↓

Mathematical setting

The research question

In the cluster editing problem you are given an undirected graph and may edit vertex pairs — add an edge where there is none, delete an edge where there is one. The goal is to turn the graph into a cluster graph: a disjoint union of cliques (every connected component is fully connected inside). Each edited pair costs 1; the task is to minimize the total number of edits. The problem is NP-hard and shows up wherever objects must be partitioned into groups of mutual friends (computational biology, deduplication, social network analysis).
