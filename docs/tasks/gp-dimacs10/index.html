Balanced graph partitioning

Split a graph into four balanced blocks while minimizing edges crossing between blocks.

The research question

The balanced graph partitioning problem: you are given an undirected, unweighted graph with n vertices. Partition the vertices into k = 4 blocks, minimizing the edge cut — the number of edges whose two endpoints land in different blocks — subject to a balance constraint: no block may hold more than floor(1.03 * ceil(n / 4)) vertices (a 3% imbalance tolerance). Graph partitioning is NP-hard.
