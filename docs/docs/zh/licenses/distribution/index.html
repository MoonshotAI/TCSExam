资源访问与分发条件 ​

中文译文供参考，许可条款以原文为准。

本指南列出 TCSExam 资源的获取途径和共享条件。 供在本地准备数据，或分发源码、数据及镜像的用户阅读。

对所选材料应用相应条件 ​

使用 tcsexam build 获取固定官方输入、验证并转换它们，再组装本地镜像。标记为 local_prepare 的资源可按其来源条款在本地准备。private_only 表示该材料不得包含在公开源码导出和公开镜像分发中。

再分发产物前，遵循下述资源具体条件，并保留所需源码、署名和声明。每行适用于指定材料和版本；镜像需要同时满足全部输入及继承层的条件。本地生成产物保留来源材料适用的限制。精确产物标识和文件范围见链接记录。

读法说明：逐资源查看。来源链接和记录标明覆盖的输入；共享条件同时适用于生成材料及包含它们的镜像。

PACE 2019 Vertex Cover 公开开发数据public-v2 归档的来源记录；Zenodo 数据集M. Ayaz Dzulfikar、Johannes K. Fichte 和 Markus Hecher 的 CC BY 4.0。范围：solver-vc-pace2019-development-data，包含使用 XZ 5.2.5 重新压缩的 100 个奇数编号公开实例。保留 CC BY 文本、PACE2019-VC-NOTICE.txt、来源和 PACE 报告链接、图实例族署名及重新压缩说明。

论文、规则 PDF、模型输出和其他外部材料原始来源及各材料具体许可遵循所共享材料的条款。软件或数据集许可仅适用于其覆盖的内容。
