Third-party notices ​

This page lists component sources, licenses and attribution requirements. It is for users reusing task materials or preparing a distribution.

Third-party terms apply to the corresponding files in task folders and containers. Original license texts are under docs/licenses/third-party/. Use distribution conditions for resource-specific sharing scope and component records for pinned source and file lists.
