# Licensing

[English](README.md) | [简体中文](README.zh-CN.md)

This guide summarizes the licenses for original and third-party TCSExam materials.
It is for users reusing source files or distributing prepared products.

Original code, checkers, scripts and build configuration are licensed under
[Apache-2.0](../../LICENSE) where TCSExam contributors hold the applicable rights.
Original task statements, explanatory documentation and website content use
[CC BY 4.0](documentation.txt). Retain existing copyright and author notices and
identify changes when sharing adaptations.

The [paper PDF](../../paper.pdf), including the copy available on the project
website, is licensed separately under [CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/).

## Third-party material

Third-party software, datasets, reference solutions, papers and generated
materials retain their source-specific terms. Use these guides for the material
you are sharing:

- [Third-party notices](THIRD_PARTY_NOTICES.md): component sources, licenses and attribution.
- [Distribution conditions](distribution.md): resource-specific access and sharing requirements.
- [Component records](full-review.md): pinned source and file inventories.
- [CPSolver source instructions](cpsolver-source.md): its source, build and library-replacement procedure.

The original license texts under `third-party/` apply as written. Materials with
unconfirmed redistribution terms are obtained and prepared locally under the
conditions in the distribution guide. Container images retain the terms of all
included data, runtime libraries and system packages.

## Combining software

When distributing a modified [GPL-3.0](https://www.gnu.org/licenses/gpl-3.0.html)
program, provide the notices and source required by its license. GPL obligations
for a combined work depend on how components are copied, linked and combined;
independent works distributed together retain their applicable terms.

An independent application using an [LGPL-3.0](https://www.gnu.org/licenses/lgpl-3.0.html)
library can use a different license while meeting the library's notice,
corresponding-source and replacement or relinking requirements. Follow the
specific license and notices of each component.

## Rights and corrections

Report attribution or license-record issues through a repository Issue, with the
affected path and source information. Rights to third-party material remain with
the respective holders.
