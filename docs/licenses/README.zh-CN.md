## 第三方材料

第三方软件、数据集、参考解、论文和生成材料保留其各自来源的条款。根据所共享的材料查阅以下指南：

- [第三方声明](THIRD_PARTY_NOTICES.zh-CN.md)：组件来源、许可与署名。
- [分发条件](distribution.zh-CN.md)：各资源的访问和共享要求。
- [组件记录](full-review.zh-CN.md)：固定来源和文件清单。
- [CPSolver 源码说明](cpsolver-source.zh-CN.md)：其源码、构建和库替换流程。

`third-party/` 下的原始许可文本按原文适用。再分发条款尚未确认的材料，依照分发指南中的条件在本地获取和准备。容器镜像保留其中所有数据、运行库和系统包的条款。

使用 [LGPL-3.0](https://www.gnu.org/licenses/lgpl-3.0.html) 库的独立应用，可以在满足该库声明、对应源码以及替换或重新链接要求的情况下采用其他许可。请遵循每个组件的具体许可和声明。
