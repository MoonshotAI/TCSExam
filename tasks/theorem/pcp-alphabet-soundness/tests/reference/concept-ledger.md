## 3. Deviations in the statements

Deviation 1 repairs a printing error. Deviations 2, 3, and 9 add side conditions needed to make statements true for degenerate parameters. Deviation 4 selects the clean “in particular” form in the paper. Deviation 5 strengthens ambient assumptions to match what the proof uses. Deviations 6 and 7 make printed quantities well-defined. Deviation 8 is an equivalent reformulation of the sampling model. Each item was checked against the source page images.

1. **For c3 (Lemma 5.23), the conclusion follows the proof: there exist C′ ≥ C·ζ^{codim W} such that the pair is (C′, ζ)-maximal.** The printed conclusion is (C·ζ^{−r}, ζ)-maximal (the p. 41 image confirms the negative exponent is printed that way in both the statement and the proof's last line). But for ζ ∈ (0,1], Cζ^{−r} ≥ C, so the proof's first step, “if already (C,ζ)-maximal, we are done,” does not work at the printed threshold: agreement is only guaranteed to be ≥ C < Cζ^{−r}. The iteration actually yields a (C·ζ^k, ζ)-maximal pair after some k ≤ r steps: agreement is ≥ C·ζ^k, each extension loses at most a factor ζ, and codimension strictly decreases, so at most r steps are needed. The remark before the printed statement (“possibly with slightly lower agreement”) also confirms that the threshold should be lower. The shipped form packages the iterative result by taking C′ := C·ζ^k. The disagreement with the independent retranslation and its adjudication are recorded in the current Lean statement.
2. **c5 (Lemma 5.14) adds the side condition 1 ≤ r.** When r = 0, the only codimension-0 subspace is the ambient space itself, so N ≤ 1. Take N = 1 and m = 2: the first branch (m members) is impossible, and the second requires W_amb to be contained in a proper codimension-1 subspace, also impossible. Thus the statement is false without the side condition. For r ≥ 1, a member's positive codimension guarantees that a hyperplane exists for the second branch. The paper does not print this condition because its applications have positive r. The independent retranslation found the same minimal counterexample.
3. **The packaged Lemma 5.24 (`ManyZoomoutsRefinement`) adds 1 ≤ r and states its first conclusion in the form used by the paper's own proof and application.** There are two issues in the printed statement. (a) For r = 0, the premises can hold (W is uniquely the full space, N = 1 ≥ q⁰, and the honest table has agreement 1), but the conclusion requires an A strictly containing W_i, which is impossible. The statement is therefore false, so 1 ≤ r is added. (b) The first printed conclusion says that every member is strictly contained in A and has codimension r′ < r inside A. At r = 1 this is impossible: strict containment gives r′ ≥ 1, contradicting r′ < 1. The paper's own proof (Section 8, Step 1, via Lemma 5.12) instead delivers a common s ≤ r for the whole family (all members have codimension s; if a t-generic family has more than one member, s ≥ 1 follows automatically). The proof of Theorem 5.26 (p. 42 image) also restates the condition as “1 ≤ r′ ≤ r₂.” In the shipped version, the conclusion quantifies over s with 1 ≤ s ∧ s ≤ r; every member is strictly contained in A, has codimension exactly s inside A, and every pairwise intersection has codimension exactly 2s inside A (precisely 2-genericity from Definition 5.11, with common member codimension). This matches both the result in Section 8 and its use in Theorem 5.26.
4. **c6 (Lemma 5.25) uses only the clean “in particular” form:** β > 4q^{−(2ℓ−r₁)} ⟹ m ≤ 16/β². This is exactly what Theorem 5.26 uses (its proof instantiates β = C). The paper's “2ℓ sufficiently large” is made explicit as 1 ≤ ℓ. The proof needs q^{2ℓ−dim W}·(q/(q−1)) ≤ 1/2 (the exact bound on the fraction of related tuples loses a factor q/(q−1); see §8.5 of the retranslation). From 20ℓ ≤ dim W, ℓ ≥ 1, and q ≥ 2, we get q^{−18ℓ}·2 ≤ 1/2. The general form (β ≥ 2q^{−2ℓ+r₁} + c ⟹ m ≤ 4/c²) is omitted. The condition on β was checked in both directions against the p. 42 image and the proof on p. 92: c is additive and outside the exponent.
5. **The main theorem (Theorem 5.26) strengthens its ambient assumption to n ≥ 2^{100}·q^ℓ, as required by the proof.** The printed statement is |V| ≥ q^ℓ (twice in the p. 42 image), but its proof uses the standing §5.3.3 assumption |V| ≥ 2^{100}q^ℓ when invoking Lemma 5.24 (p. 40 image: “say |V| ⩾ 2^{100}q^ℓ to be concrete”). The condition dim(V⋆) ≥ 2^{100}·(2ℓ) needed for Lemma 5.18 follows from n ≥ 2^{100}q^ℓ − 10/δ when ℓ is large (the exponential term dominates the linear one). “ℓ sufficiently large” (∃ ℓ₀ ∀ ℓ ≥ ℓ₀) absorbs all such requirements, including C ≥ q^{−2(1−δ³)ℓ} ⟹ C > 4q^{−(2ℓ−r₁)} and dim W_i ≥ 20ℓ.
6. **The parameter t is implemented as ⌈2^{2+10/δ₂}⌉!** The printed formula is t = (2^{2+10/δ₂})! (the p. 41 image confirms that the factorial applies to the entire power). Since 2^{2+10/δ₂} need not be an integer, its factorial is undefined. The bounds are monotone in t (both the threshold for N and the final upper bound increase with t), so taking the ceiling has no material effect.
7. **The packaged Theorem D.1 (`GenericListDecodingBound`) adds side condition 1/M ≤ γ.** If γ < 1/M, the printed condition δ > 1/M + √((γ−1/M)(1−1/M)) has a non-real radicand (the statement can be regarded as vacuous in that region). Lean's `Real.sqrt` is defined as 0 on negative inputs; without this side condition, the packaged assumption would strengthen the paper's claim into a region where it made no assertion. The paper always applies the result with γ = 1/M, making the square-root term zero, so the added condition does not affect any use.
8. **Sampling model for the inclusion test: uniform over the filtered pair set {(L₁,L₂) : L₂ ⊆ L₁}.** The paper samples sequentially (uniform L₁, then uniform L₂ ⊆ L₁). Every ℓ₁-dimensional L₁ has the same number of ℓ₂-dimensional subspaces, given by a Gaussian binomial coefficient depending only on dimensions, so both sampling schemes have the same distribution. The claims c1 and c2 hold exactly in this model (completeness 1; average acceptance probability exactly q^{−ℓ₂}).
9. **c5 (Lemma 5.14) also adds the side condition that S is nonempty.** Take S = ∅, dim Wamb = 0 (for example, n = 1, F = 𝔽₂, Wamb = ⊥), r = 1, and m = 1. The first branch asks for m ≥ 1 members from an empty family, which is impossible. The second asks for H ≤ ⊥ with relCodim ⊥ H = 1, also impossible because relative codimension is always 0 in a zero-dimensional space. Thus the statement is false as written. Deviation 2 fixed the r = 0 degeneration but missed this case: when r ≥ 1 and S is nonempty, the member-codimension condition forces dim Wamb ≥ r ≥ 1, which automatically ensures that the hyperplane in the second branch exists. The empty family is the only remaining corner case. The paper does not state nonemptiness; its degree argument needs a vertex of high degree (implicitly N ≥ 1), and its applications always use a nonempty family (the calls in Lemma 5.12/Corollary 5.15 include a lower bound on N). With the repair, the counterexample no longer satisfies the premises (`hSne` is unprovable for an empty set), while all valid paper parameters remain covered.

A **scope note** (not a deviation): trivial barrier two from §1.2.1 (a family of codimension-1 subspaces, with Ω(q^{ℓ₂−ℓ₁}) behavior) is omitted. The paper only sketches its analysis (“with constant probability, L₂ has Θ(q^{ℓ₁−ℓ₂}) candidate i”); formalizing it requires subspace-containment counting plus a second-moment argument, at a cost disproportionate to its value as a checkpoint. Barrier one (c2) already captures the point that the traditional soundness threshold stops at q^{−ℓ₂}. Omitting barrier two does not affect any downstream statement.

## 4. Degenerate-parameter checks (substitution records required by SOP 6.5, item 2)

Each checkpoint is checked after substituting the empty set, zero dimension, zero repetitions, or a singleton. These checks explain the side conditions.

- **c1:** If ℓ₂ = 0, then L₂ = ⊥, the linear function is unique, and the acceptance probability is 1 = q⁰ ✓. If ℓ₁ = ℓ₂, then L₂ = L₁ ✓. If ℓ₂ ≤ ℓ₁ ≤ n is not assumed, the random-pair set is empty and the acceptance rate is 0/0 = 0 ≠ 1, so the statement is false; hence both dimension side conditions.
- **c2:** Under the same side conditions, the random-pair set is nonempty. Averaging over the full table space gives exactly q^{−ℓ₂}: for each pair (L₁,L₂), the restriction map Hom(L₁,F) → Hom(L₂,F) is a surjection with uniform fibers, so exactly a 1/q^{ℓ₂} fraction of restrictions agree. Some table pair attains the average ✓. When ℓ₂ = 0, the right side is 1 and every table has acceptance probability 1 ✓.
- **c3:** An empty zoom has agreement 0 < C (because hC : 0 < C), making the premise false; this is vacuously safe. Extension enlarges the zoom, so nonemptiness is preserved upward ✓. If r = 0 (W is the full space), there is no strict extension and the second conjunct of (C,ζ)-maximality is vacuously true; the iteration stops after k = 0 steps ✓. If ζ = 1, then Cζ^k = C, so the statement holds directly ✓. If C > 1, the premise is impossible because agreement ≤ 1 < C, again vacuously ✓.
- **c4:** When N < j, the j-generic premise is vacuously true; a (j+1)-generic condition on S′ is vacuous when |S′| < j+1. Choosing S′ = S works because N ≥ N^{1/j}/q^r follows from N^{1−1/j} ≥ 1 ≥ q^{−r} for N ≥ 1; N = 0 is trivial ✓. If r = 0, then N ≤ 1 because there is only one codimension-0 subspace, so the same argument covers it ✓. For the main case N ≥ j, each j-subset has at most q^{jr} bad members (there are at most (q^{jr}−1)/(q−1) ≤ q^{jr}−1 hyperplanes; more than q^{jr} bad members would force a collision on one hyperplane, a contradiction). Thus N ≤ s + C(s,j)·q^{jr} ≤ s^j·q^{jr}: for s ≥ j+1, C(s,j) ≥ s and 2·C(s,j) ≤ s^j because j! ≥ 2; for s = j, j + q^{jr} ≤ j^j·q^{jr} because j^j ≥ j+1. The printed bound N^{1/j}/q^r follows exactly, with no constant adjustment.
- **c5:** The r = 0 counterexample is in deviation 2. If S = ∅ and dim Wamb = 0, neither branch of the disjunction holds (the earlier check in this section verified only the second branch's cardinality inequality 0 ≤ 0 and missed existence of H); deviation 9 repairs this by requiring S nonempty. If m = 1, take a singleton subfamily (2-genericity is vacuous) ✓. If m ≥ 2 and N < m, the first branch is impossible and the degree argument in the proof gives the second branch (some vertex must then have degree at least ⌈N/m⌉ ≥ 1) ✓.
- **c6:** If dim Q > 2ℓ or 2ℓ > dim W, the zoom is empty and agreement is 0 < β (hβ gives β > 0), so the premise is false, vacuously ✓. For m = 0, 0 ≤ 16/β² ✓. If β > 1, no function can satisfy the premise ✓.
- **Main theorem:** If there are no (C,1/5)-maximal pairs, the count is 0 ≤ the right side ✓ (all factors on the right are positive). The same holds when C > 1 ✓. If r₁ = 0 (Q = ⊥), maximality reduces to the simpler form of Definition 5.22, and the statement still holds.

## 5. Checking uses of packaged assumptions

For each call to a packaged assumption in the main-theorem proof route, the theorem's premises are checked to imply the premises at the call site.

- **Call to `ManyZoomoutsRefinement`** (Step 2 of the proof of Theorem 5.26, on the complement after decomposing Q ⊕ A₀): the dimension parameter 2ℓ − r₁ serves as 2ℓ, the codimension r₂ satisfies r₂ ≤ 10/δ, and C is unchanged. Its N premise q^{100(t−1)!r₂²(ℓ−r₁/2)/ξ} follows from the main theorem's N ≥ q^{100(t−1)!(10/δ)²ℓ/ξ} (r₂ ≤ 10/δ and ℓ − r₁/2 ≤ ℓ, so the exponent inequality points the right way) ✓. The C premise q^{−2(1−δ⁵)(ℓ−r₁/2)} ≤ C follows for large ℓ from C ≥ q^{−2(1−δ³)ℓ}: note that δ³ ≤ δ⁵ is false—in fact, for δ < 1, δ³ > δ⁵, so (1−δ³) < (1−δ⁵), and q^{−2(1−δ³)ℓ} > q^{−2(1−δ⁵)ℓ} ≥ q^{−2(1−δ⁵)(ℓ−r₁/2)}·q^{(1−δ⁵)r₁}. It is enough that 2δ³ℓ ≥ (1−δ⁵)r₁ in scale, which ℓ₀ absorbs ✓. The bound r₂ ≥ 1 follows from N > 1 for the largest class (the codimension-0 class contributes at most one distinct W) ✓; this is where the side condition from deviation 3 is used.
- **Call to `GenericZoomSampling`** (Step 4, ambient space V⋆, a = r₁, r = r₂, j = 2ℓ): ℓ₀ absorbs j ≥ 2^{100r₂²r₁²} ✓; n ≥ 2^{100}q^ℓ gives dim(V⋆) ≥ 2^{100}·2ℓ ✓. The family is 2-generic with common codimension: the packaged conclusion's uniform-s form (deviation 3) is preserved by translation W_i = W_i′ ⊕ Q, which keeps codimensions unchanged ✓. The subfamily-size lower bound > 0 gives S nonempty ✓.
- **Call to `GenericListDecodingBound`** (inside c6): γ = 1/M satisfies the side condition from deviation 7 ✓. Let δ := β/2; hβ : β > 4q^{−(2ℓ−r₁)} = 4/M gives δ > 1/M ✓.
