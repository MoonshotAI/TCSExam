## 3. Deviation list (content and reason for each item)

1. **All Big-O/Θ/Ω constants are made explicit.** c2–c6 have an outer `∃ C` (c2 uses 0 < C; the others use 1 ≤ C), shared by multiple occurrences in the same statement; c7 uses `∃ C, ∃ c`. The paper’s hidden constants in O(·) are absolute, so this is equivalent to “there is an absolute constant.” The `α^{O(k+ℓ)}` in c2 becomes `α^(C·(k+ℓ))`; the γ premise in c3, `(ατ)^{O(ε⁻²k²log(1/α)+ε⁻¹k log(1/τ))}`, becomes `(α*τ)^(C·(k²·log(1/α)/ε² + k·log(1/τ)/ε))`. Note that when the base is below 1, increasing C strengthens the premise, consistent with an existential C for which the proposition holds (the proof supplies a particular C). All logarithms use the natural base; the paper leaves the base unspecified, and Big-O absorbs the difference.
2. **c7 (Theorem 7.9) has an explicit nondegeneracy premise**: `(1 + log(|G|²/|A|))^600 ≤ c·log|G|`. The printed theorem is an unconditional Big-O statement. Its proof’s Bohr-set size estimate (Lemma 6.2: |B| ≥ ε^d·|G|, where ε is the radius and d the dimension) yields a nonvacuous conclusion only when log(1/α) is not too large relative to log|G|—the final line, `ν(B₂)^{O(rank)}|G|² ≥ 2^{−O(log(1/α)^600)}|G|²`, requires ε^d·|G| to be in a valid range. The premise makes that range explicit (c absorbs the O constant). This is the only substantive statement-level deviation in the task. The `1 +` inside the logarithm (i.e. log(e/α)) was added in the 2026-08-19 repair; see Deviation 11. The derivation of c8 from c7 is in Section 4.
3. **Clause (6) of c4 (Lemma 5.16) averages over the coset x₀+W** (the coset containing X), rather than over the linear W in the paper’s notation. Reason: the first-coordinate support of A∩S(X,Y,D) lies in x₀+W. If the average were literally over the linear subspace W and the coset were disjoint from W, the left side would be 0 while the right side would be positive, making the statement false. The paper restates and uses it in §5.7 with the same coset interpretation (there W is already linear and x₀ = y₀ = 0, so both readings agree).
4. **Density-range premises in c5/c6:** c5 adds `0 < α < 1`, `0 < γ`, and `0 < |X|,|Y|,|D|`; c6 adds `0 < α ≤ 1` and the same positivity conditions. The paper assumes density semantics here (δ_X, etc. are subset densities). These are needed: c5’s density increment (1+ε/C)α can exceed 1 for large α, making the claim impossible; positivity ensures δ > 0, so logarithms and powers are defined.
5. **Handling εs in c5:** the paper says “set εs = Θ(ε) sufficiently small.” The package makes this `∀ εs` with premise `0 < εs ≤ ε/C` (C is the outer constant). The algebraic-spread premise uses (r, εs), as in the paper.
6. **c2/c3 output g₁,g₂ are [0,1]-valued functions,** exactly as in Theorems 3.4/3.5. In the paper’s application in Lemma 5.13, Lemma 3.3 changes them to {0,1}-valued functions. Lemma 3.3 is proof content, not a checkpoint (it is a standard convex decomposition and offers little value as a task).
7. **No external facts are packaged as assumptions.** Statements c1–c8 are self-contained. The two Kelley–Meka results (Lemma 5.2: convolution bound for algebraically spread sets; Lemma 5.3: near-constancy of convolution for spread sets), spectral positivity (Lemma 4.2), and the Bohr-set machinery (§6) occur only in proofs. Unlike the odd-query package, which packages three external facts, none of the eight checkpoint statements here needs them.
8. **Lower bound on p in c6:** `p ≥ C·log(1/(αδ_D))/ε⁴`. The paper writes `p = Ω(log(1/(αδ_D))/ε⁴)`; this makes the absolute constant explicit. p ≥ 1 is also stated (the paper takes p to be a positive integer).
9. **Bipartite representation in c1:** the paper’s G = ([k]∪[ℓ], E) becomes `E : Finset (Fin k × Fin ℓ)`, with the left side [k], the right side [ℓ], and edges as ordered pairs. A designated edge (i₀,j₀) belongs to E. The functions for other edges are `f : Fin k → Fin ℓ → ι → κ → ℝ`, required to take values in [0,1] only on E.erase (i₀,j₀). The two expectations in the conclusion are over the uniform distribution on (Fin k → ι) × (Fin ℓ → κ), i.e. x₁..x_k and y₁..y_ℓ are independently uniform, as in the paper.
10. **Finite-field representation in c4:** F₂ⁿ is `Fin n → ZMod 2`; |F₂ⁿ|² = (2^n)² = 4^n is written as `(4:ℝ)^n`; α is not named separately, but is inlined as `A.card/(4:ℝ)^n` in the premise and in the arguments for δ.
11. **Exponent in c7 changed to `1 + log(|G|²/|A|)`**. A dense-set counterexample refuted the formulation without this condition (the original form in Deviation 2, with exponent `log(|G|²/|A|)^600`): take G = ZMod(2^m), A = G×G with one point removed. Then log(|G|²/|A|) ≈ |G|⁻², so the nondegeneracy premise holds easily, while cornerCount A = |G|³ − 3|G| + 2. The old lower bound, 2^{−C·log(|G|²/|A|)^600}·|G|³ ≈ |G|³·(1 − O(|G|⁻¹²⁰⁰)), is strictly larger for large m. zip`; analysis report `corners-quasipoly-ladder.md`). Checking the paper: the printed Theorem 7.9 bound, Pr ≥ 2^{−O(log(1/α)^600)}, is also false literally as α → 1. The proof’s parameter choices (K = O(log(1/α)³⁰), r = O(log(1/α)³⁵⁰), etc.) are valid only when log(1/α) has a positive lower bound; the printed theorem’s Big-O hides that range. Repair: take L := 1 + log(|G|²/|A|) (equivalently log(e/α)), so L ≥ 1. In the sparse range, L⁶⁰⁰ and log(1/α)⁶⁰⁰ differ only by a constant factor, absorbed by the outer C, matching the proof. In the dense range, log(1/α) is bounded, cornerCount ≥ |G|³(1 − 3(1−α)), and the proof’s first branch gives Pr ≥ α³/10; both are constant-factor lower bounds, and 2^{−C·L⁶⁰⁰} ≤ 2^{−C}, covered by choosing C large. The nondegeneracy premise is updated to L⁶⁰⁰ ≤ c·log|G|, with the same intent. The corresponding c8 update is in Section 4.
12. **The ε range in c2 is now `ε ∈ (0, 1)`**. The formulation without this condition required only `0 < ε` and was false: take f ≡ 1, α = 1, ε = 2; the conclusion’s size bound reads 2 ≤ E[g₁]·E[g₂] ≤ 1, a contradiction.  Checking the paper: Theorem 3.4 is printed as “for any ε > 0,” but its last proof step discards the first sum term from E[g₁]E[g₂] ≥ E[f·g₁·g₂] ≥ (1−ε)α·E[g₁]E[g₂] + εα^{O(k+ℓ)}, which is valid only for ε ≤ 1. The companion Theorem 3.5 (c3) explicitly states ε ∈ (0,1). Thus ε < 1 is an implicit range in the paper and is made explicit here (same kind of fix as Deviation 4).

## 4. Main-theorem assembly check (derive c8 step by step from c7)

Let (C,c) be the constants from c7. Let A be corner-free, and write L := 1 + log(|G|²/|A|), the repaired form from 2026-08-19; hence L ≥ 1 and log(1/α) = L − 1, with α = |A|/|G|² ∈ (0,1]. If A is empty, the proposition is vacuously true.

1. Corner-free implies cornerCount A = |A|: when d ≠ 0 the three points are distinct ((x+d,y) = (x,y+d) iff d = 0), and a corner-free set contributes no such triple; when d = 0 all three points coincide at (x,y), so every point is counted once. (Executable confirmation in small examples E5d/E6b.)
2. If L^600 ≤ c·log|G| (the c7 premise holds), then c7 gives |A| = cornerCount ≥ 2^{−C·L^600}·|G|³. Substitute |A| = α|G|² to obtain α ≥ |G|·2^{−C·L^600}. Take natural logarithms: log|G| ≤ C·(ln 2)·L^600 − (L − 1).
3. Combine with the premise log|G| ≥ L^600/c: L^600/c ≤ C·(ln 2)·L^600 − (L − 1), or L^600·(1/c − C ln 2) + (L − 1) ≤ 0.
4. c can be chosen smaller: c7 is existential, and choosing a smaller c strengthens its premise and weakens the proposition, so any valid (C,c) yields any (C,c') with c' < c. Choose c < 1/(C ln 2). The first term in the left side of step 3 is positive (L ≥ 1 and its coefficient is positive), and the second term is nonnegative, a contradiction. Thus the branch where the premise holds cannot occur. (Before the repair this branch implied L = 0, i.e. α = 1, requiring enumeration of small groups; with L ≥ 1 the contradiction is direct and shorter.)
5. If L^600 > c·log|G| (the premise fails), then log(1/α) > (c·log|G|)^{1/600} − 1, hence |A| < e·|G|²·exp(−c^{1/600}·(log|G|)^{1/600}).
6. Absorb the factor e: when (c·log|G|)^{1/600} ≥ 2, e·exp(−x) ≤ exp(−x/2), with x = c^{1/600}(log|G|)^{1/600}. The remaining case has log|G| < 2^600/c, so only finitely many group orders. Every nontrivial group (|G| ≥ 2) has corners in the full set (choose any x,y,d ≠ 0), so a corner-free A satisfies |A| ≤ |G|² − 1. For each such group, this is a strict upper bound, and c₈ can be made small enough to satisfy |A| ≤ |G|²·exp(−c₈(log|G|)^{1/600}) for each one. For |G| = 1, the right side is 1 ≥ |A|.
7. Choose c₈ to be the minimum of c^{1/600}/2 and the finitely many small-group constraints from step 6. Both cases give |A| ≤ |G|²·exp(−c₈(log|G|)^{1/600}). ∎ (The equality in step 1 was checked with small examples; whether the c7 premise is valid is recorded in Deviation 2, and the exponent’s 1 + repair is Deviation 11.)

## 5. SOP 6.5 systematic error-pattern self-check

1. **Are existential outputs constrained?** For c2/c3, the outputs g₁,g₂ are linked to input f by the correlation inequality E[f·g₁·g₂] ≥ (1−ε)α(τ)·E[g₁]E[g₂] and a size lower bound; both are present. Without the size lower bound, g₁=g₂=0 is trivial; without the correlation condition, g₁=g₂=1 need not work—both conditions are necessary and included. For c4, outputs W,x₀,y₀,X,Y,D are tied to A by the containment conditions (X ⊆ x₀+W, etc., in (1)/(2) and the built-in X ⊆ carrier in AlgSpreadWithin), and by all six conclusions corresponding to paper clauses (1)–(6). Degenerate-value test: if X=Y=D are full cosets, (2)/(3) require δ̃_D,δ ≤ 1 (true since they are exponentials with negative powers). For (5), does container spread hold for f=1_S when A is the full space? The right side of the AsymSpread conclusion is (1+ε)E[f]E[g₁]E[g₂]. If A is full, then on Y×D, F₁(y,d)=1_{(y+d,y)∈S}; for full-coset X,Y,D, (y+d,y)∈S always, so F₁ ≡ 1, and E[F₁g₁g₂] = E[g₁]E[g₂] = (1+ε)·1·E[g₁]E[g₂], so it holds with equality. Clause (6) has row average = δ_D = 1 ≥ (1−2√ε)·1·1·1. α* = 1 ≥ α = 1; for A full, α=1, log(1/α)=0, δ̃=δ=1, so the r ≥ 0 premise is vacuous. Thus the full-set case is true. The premise `0 < A.card` excludes empty A (the statement is vacuously true).
2. **Were degenerate parameters tested?** For c1, E = ∅ makes hE : (i₀,j₀) ∈ ∅ false, so the statement is vacuous; E = {(i₀,j₀)} makes the erased empty product equal 1, and the statement reduces to the spread definition itself (the f=g=1 case). There is no k,ℓ ≥ 1 premise in c1: at k=0, `Fin 0 → ι` is a singleton, but i₀ : Fin 0 cannot exist, so hE is unsatisfiable and the statement is vacuous. If c2’s premise α > gridNorm cannot hold, it is vacuously true. For c7 with |G| = 1, log|G| = 0, and the premise (1 + log(...))^600 ≤ 0 is impossible (left side ≥ 1), so the statement is vacuous. The case |G| = 1 in c8 is checked in step 6 of Section 4.
3. **Are the main theorem’s premises at least as strong as the premises at its checkpoint call sites?** c8 invokes c7 once with premise L^600 ≤ c·log|G|; in the branch where it fails, the c8 proof derives the bound directly (Section 4), so no premise is missing. For c5 invoking c3 at the proof level, c3’s γ premise, γ ≤ (ατ)^{C(...)} matches c5’s γ premise (base αδ_Xδ_Y and τ=(1+8εs)δ_X) under the substitution in the proof; this is not a statement-level invocation.
4. **Are substitution points / evaluation points consistent?** Φ uses the original form at the start of §5.4, f₁(x,y)f₂(y+z,y)f₃(x,x+z); F₁(y,z)=1_A(y+z,y) and F₂(x,z)=1_A(x,x+z) match the paper exactly (note F₁ is (y+z,y), not (y,y+z); small example E5 checks container membership). The expectation point in clause (6) of c4 is the coset x₀+W (Deviation 3).
5. **Are base cases present?** c3 has k ≥ 1; c4 has r,s,t ≥ 1; c6 has p ≥ 1; c2 has k,ℓ ≥ 1. The ε endpoint ranges c4 ε ∈ (0,1/64), c5 ε ∈ (0,1), and c6 ε ∈ (0,1/10) match the paper. c2’s ε ∈ (0,1) explicitly states the paper’s implicit range.
6. **Were two-sided conditions reduced to one-sided ones, or boundaries shifted by one?** Both c5 branches (F₁-side and F₂-side) remain; all three premises in c6 (two norms and the row lower bound) remain; all six conclusions of c4 remain. Directions of c1’s inequality (≤ τ·...+γ) and c2/c3’s correlation inequality (≥) were checked. The 1/(kℓ) power in gridNorm and the 2k power in c3’s premise were compared (∥f∥^{2k} ≥ (ατ)^{2k} iff E[∏] ≥ (ατ)^{2k}, by monotonicity of powers).
7. **Weakening and vacuity checks:** c7 has a stronger premise than the paper (an added nondegeneracy condition), hence a weaker proposition; this is recorded in Deviation 2 (the exponent’s 1 + repair is in Deviation 11). The converse, whether the premise can be vacuous, was checked: take G = F₂ⁿ large and A of constant density; then (1 + log(1/α))^600 is a constant and can be ≤ c·log|G|, so it is inhabited and not vacuous. c4’s premise r ≥ Cε^{-8}log(1/δ)^8 can be met by taking r sufficiently large (δ depends on C but is fixed by the definition), so it is satisfiable. c2’s premise α ≤ gridNorm can be met by choosing α small.
