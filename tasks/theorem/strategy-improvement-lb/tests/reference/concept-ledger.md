## 3. Deviation list (all intentional differences from the paper)

1. **Priorities use ℕ** (the paper allows any finite Q ⊂ ℤ). This does not affect G_n or the sink-game reduction; the main theorem concerns only G_n.
2. **The main theorem is stated only for parity games.** The mean-payoff and discounted-payoff extensions in Theorem 1, and the clause about “all currently used value functions in the literature,” are not formalized. The paper derives them from an argument similar to [15, Theorem 4.19] and a note on equivalence of value functions; this task does not include complexity classes or the infrastructure for those value functions.
3. **Proposition 7 states only the lower-bound direction** (“the optimal pair does not occur in an earlier iteration”). The matching upper bound (reaching it in exactly 2^{n+1}−3 steps) is not stated. Theorem 1 needs only the lower bound, and the upper bound depends on more deterministic details of the SWITCH-ALL choice.
4. **Iteration representation:** use a nondeterministic step relation (counterstrategy choice is existentially quantified) and legal chains; “at least 2^{n+1}−3 iterations are required” is expressed as “no chain of length ≤ 2^{n+1}−3 ends in an optimal pair” (chain length L = iteration count + 1).
5. **Observations 8 and 9 are combined in one checkpoint:** the two reset branches’ premises are combined (the paper uses them separately). The extra information in Observation 9, “the differing position q of the two value vectors satisfies q ≥ 2j+1,” is not in the statement (that branch is used in the induction only to argue that “a_{j+1}, d_{j+1} can be pretend-deleted”; it is internal to the proof).
6. **SWITCH-ALL is universally quantified:** quantify over every rule satisfying “select an edge for each node with an improving edge.” The original does not specify how to choose among several edges; the transfer argument in Lemma 12 does not depend on that choice (checked in small example E9).
7. **Admissibility is an explicit premise:** in the paper’s setting, c3–c6 apply to strategies during an SSI run, where admissibility is guaranteed by an algorithm invariant. The Lean statements list admissibility and the sink-game property as explicit premises.
8. **c2’s uniqueness is stated as pointwise equality on the owner’s nodes**. The original conclusion was subtype equality `σ = σstar n`, which is false literally: strategies are total functions, constrained by outgoing edges only on the owner’s nodes, and `step`/`xi0`/`IsOpt0` read only the owner’s values. Therefore, changing `σstar` at d-nodes (for example, at n = 1, choosing ⟨0,_⟩ rather than ⟨1,_⟩ at index 2) gives an optimal strategy unequal to σ*, so one direction of the iff is false. The paper defines a strategy only on its owner’s nodes, so “there is a unique strategy that goes from every a_i through d_{n+1}” holds under its convention. The repaired conclusion is `∀ v, owner v = false → σ.1 v = (σstar n).1 v` (with the dual statement for τ), matching the paper pointwise. Counterexample probes in `probes` confirm that the changed σ satisfies the right side of the new statement (so it is no longer a counterexample) while σ ≠ σstar still holds (the formulation without this condition remains false). A positive probe confirms that σ*/τ* themselves satisfy the right-side predicate, so the new statement is not vacuous. The conclusions of c7/c8 use the behavioral predicates `IsOpt0`/`IsOpt1` and do not use c2’s equality form; the main-theorem chain is unaffected.
9. **c5’s phase premise requires the whole chain above j**. The old premise gave only single-edge conditions `σ.1 (aN n j) = aN n (j+1)`, `τ.1 (dN n j) = dN n (j+1)`, and was false literally. The model’s counterexample (n = 3, j = 2, compile-confirmed) used σ taking a_1→a_2→a_3→d_4, satisfying the single-edge premise, and an optimal counterstrategy for player 1 taking d_1→d_2, d_2→d_3, d_3→⊤, which does not reset at d_2 (it takes d_3 rather than d_1). From d_2 the d-chain accumulates only even priorities 6 and 8; both the reset route and the route through a_3 are sent by σ to d_4, whose maximum even priority in the graph is 10, so they are strictly worse for player 1. The model therefore derived False from the first conjunct of old c5 (`c5_axiom_gives_false`), and the submission collector’s detector assigned zero to everything. The dual mechanism also makes the second conjunct false (if τ sends d_n directly to ⊤, player 0 at a_j strictly prefers going up the a-chain to d_{n+1} over resetting; this was confirmed by analysis but not recompiled). The proof of Observation 8 assumes the SSI phase invariant: during a phase, the a-chain above j remains unbroken (σ(a_i) = a_{i+1} until a_n → ⊤, not through d_{n+1}); “player 1’s goal is to reach a_{j+1} without passing d_{j+1}” holds only in that context. For a single edge, player 1 has a third option (continue upward along the d-chain), which the paper does not discuss separately. Repair: strengthen both single-edge premises to the full chain above j (`∀ i : ℕ, j ≤ i → i ≤ n → σ.1 (aN n i) = aN n (i+1)`, with the dual condition for τ), the form actually maintained by the phase invariant in Proposition 7’s induction. Probes (`verify-ctx/probes/Probes.lean`, added to the build as a regression test) confirm that the model’s counterexample satisfies the old single-edge premise (`by decide`) but violates the new a-chain premise (at i = 3, σ(a_3) = d_4 ≠ ⊤, decidably false, so the counterexample is excluded); the dual strategy also violates the new d-chain premise. Positive probe: initial strategies σ₀/τ₀ satisfy both full-chain premises at (3, 2), so the new premise is inhabited. The c7 call establishes the phase invariant in full-chain form, as in the paper’s induction (see Section 4).

## 4. Checkpoint-premise audit (at the main-theorem call sites)

Item 3 of SOP 6.5 requires the main theorem’s premises to be at least as strong as those required by every checkpoint it uses.

- c8 invokes c7: the c8 premises (hn, ImpRule, legal chain, chain length) match c7’s, while c7 additionally requires IsSwitchAll. The c8 proof first handles an unrelated switch and then invokes c7, following the structure of Lemma 12 in the paper. ✓
- c7 invokes c5/c6: c5/c6 require j ∈ [2,n], a phase condition, and admissibility. c5’s phase condition is the full chain above j=a_{i+1} and τ(d_i)=d_{i+1} for every j ≤ i ≤ n); c6 still uses the single-edge form. These are phase-induction invariants established by the proof. The observations are stated in that context: during the paper’s phase strategy, the full chains above j remain intact. ✓
- c7 invokes c3 (Lemma 5: every nonoptimal pair has a switch): c3 requires the sink-game property, admissibility, and existence of counterstrategies; the definition-layer lemmas exists_counter0/1 ensure the premise is satisfiable, so it is not vacuous. ✓
- c2 provides the expansion of “optimal” for c7/c8 (IsOpt iff pointwise equality with the explicit strategy on the owner’s nodes; Deviation 8). Its only premise is n. ✓

## 5. SOP 6.5 systematic error-pattern self-check

1. **Are existential outputs constrained?** c7/c8 conclude a universal statement with a negation (no output object); c2’s outputs σ*/τ* are explicit constructions with an iff relationship. ✓
2. **Degenerate parameters:** when n=0, 2^{n+1}−3 = 0, and every nonempty chain makes c7/c8 vacuously true; the main theorem excludes this with hn : 1 ≤ n. The range j ∈ [2,n] for c5/c6 is empty when n=1 (consistent with the paper separately verifying G_1 as the induction base case; recorded here). c1/c2 hold for n=0 (G_0 is trivial). ✓
3. **Are the main-theorem premises at least as strong as those required at each checkpoint call?** See Section 4. ✓
4. **Are substitution points consistent?** The priority functions 2i+1, 2i+2, 2n+4 and the edge table were checked point for point against Table 1. A Python simulator using the same indexing produced the same five-phase trajectory as the proof of Proposition 7, independently confirming there is no off-by-one error.
5. **Base cases:** the c7 induction base case n=1 (2²−3 = 1, one iteration reaches the optimum; checked by simulator E8) is part of the c7 proof. The j ≥ 2 premise is explicit in c5/c6 (for j=1, (d_1,d_1) and (a_1,a_1) are not legal edges, so the statement would be false; these cases are excluded).
6. **Two-sided conditions / off-by-one boundaries:** the conversion between iteration count 2^{n+1}−3 and chain length ≤ 2^{n+1}−3 is derived (chain length = number of iterations + 1) and numerically checked by simulator E8 (n=1,2,3 gives 1,5,13 steps).
7. **Weakening and vacuity:** the two weakenings (trimming the differing-position branch of Observation 9 and not stating the Proposition 7 upper bound) are recorded with reasons. The IsCounter premises in c3/c4 are satisfiable by definition-layer exists_counter0/exists_counter1, so they are not vacuous. ✓
