# Executable Small Examples for `lean-monotonicity-test-lb`

This pure-Python port of the Lean definition layer checks checkpoint predicates on small instances. It records the output of each run.

Ported script: `small_examples.py` (run successfully; output `ALL SMALL EXAMPLES PASSED`). Fidelity details: nodes are tuples of length L, with positions ≥ the layer count filled by 0 (matching Lean's `zeroPt` prefix convention); a walk advances when one child edge is active, stops with none when zero are active, and stops with multi while recording the two smallest indices when at least two are active. The function `f_{M,H}` uses strict truncation thresholds and includes endpoints in the middle layer. The outcome's P/R/ρ update rules correspond item by item to §3.4, Step 1 and its three cases.

## Results

- **E1 (hand check of ΓM):** L=2, N=2, s=1, n=4; every label uses coordinate 0 as the tree. For x=1111, both term edges in the first layer are satisfied, so the walk stops with multi (even layer) → 1*. For x=0000, no term edge is satisfied, so it stops with none (even layer) → 0*. For x=0111, the result is 0*. All cases match the definition.
- **E2 (exhaustive check of c1 = Lemma 9):** With the same parameters, enumerate all 4096 trees × 16 leaf-constant assignments = 65,536 yes-support functions, and check monotonicity at all 16 points for each function. Every case passes. This completely verifies “yes is always monotone” for these small parameters, including the boundary between the truncated region and the middle layer.
- **E3 (Lemma 8 engine, the lemma folded into c1):** Across 400 trees and all middle-layer bit-flip cases (12,800 cases total): when ΓM(x) is a leaf u, ΓM(xⁱ) ∈ {u, 1*}; when ΓM(x) = 1*, ΓM(xⁱ) = 1*. No counterexample.
- **E4 (agreement between f's values and ΓM):** Spot checks confirm pointwise agreement: in the truncated region f takes the boundary values (1 above the upper threshold and 0 below the lower threshold); in the middle layer its value is determined by ΓM or the leaf function.
- **E5 (exhaustive check of c2 = Lemma 5):** For all 256 Boolean functions at n=3, every pairwise-disjoint subfamily S chosen from the set of violating point pairs satisfies |S| ≤ dist(f, monotone). The distance is computed by brute-force minimum over all 20 monotone functions on n=3. No counterexample.
- **E6 (mechanism check for c3 = Lemma 10):** For n=4, s=2, sample 300 no instances at random (tree + secret variable + symbol bit at each leaf). The “same leaf + anti-dictator” event occurs 10 times. Each occurrence yields a monotonicity violation (f(x)=1 > f(xˢ)=0), and the violating edges gathered within each sample are pairwise disjoint (the input condition for c2). The expected count at this size is 0.033. The Ω(1) probability per edge is asymptotic; at n=4, the middle layer is already the whole cube and (1−2/√n)^s = 0, so the rate is not visible. This example checks only the mechanism and disjointness; the rate is cross-checked item by item in `concept-ledger`.
- **E7 (numerical check of c4 = Lemma 15):** For n=4, s=1, enumerate the query sets of all 24 trees × 3 middle-layer points. For every yes/no leaf-function sample, compute exact α_M and β_M, then check every outcome O consistent with M and safe (ρ constant and 2|B| ≤ n) against α_M ≤ (1 + 2|B|/n)·β_M. All 24 cases pass, including exactness of α_M = 2^{−m′}.
- **E8 (rate in c5 = Lemma 19):** Numerically check that substituting q = n^{1/2−1/(4ℓ+2)}/log₂n into `B ≤ 4^{2ℓ−1}·(2q)^{1+1/(2ℓ)}·250·s·log₂n` gives `B/n = 4^{2ℓ−1}·2^{1+1/(2ℓ)}·250·(log₂ n)^{−1/(2ℓ)}` for ℓ = 1,2,3 and m = 10…10⁵, with relative error < 10⁻⁹. The power of n cancels exactly; o(n) comes entirely from the logarithmic loss, as asserted at the end of §4.1. The threshold where it drops below 1/2 is at log₂ n = (2·const)^{2ℓ}: astronomical but finite.
- **E9 (smoothing lemma, Lemma 26, folded into c5):** For 2,000 random instances (random β and α, plus a nonnegative sequence scaled so Σp = 2β), the inequality Σ min(β, p_j^{1+α}) ≤ 4β^{1+α/(1+α)} holds in every case.
- **E10 (double-counting core of c6 = Claim 28):** On small instances (s=2, n=4, t=1, random A ⊇ Δ and R), directly check the degree bounds in both parts of the bipartite graph: each point on the U′ side has at most |A∖Δ|^t neighbors; each point on the V side has at least binom(s−|R|, t)·|Δ|^t neighbors when |R| ≤ s. The total number of edges lies between |V| times the lower bound and |U′| times the upper bound. All 300 cases pass. The premise of the full conclusion 50^t|V| ≤ |U| requires 100·s·t ≤ n; the smallest feasible n is about 10⁶, too large for enumeration. Thus this example checks the proof's core counting mechanism.
- **E11 (structural facts about outcomes, instantiated as c5 premises):** On 60 random (tree, query-set) pairs, verify: (i) the outcome agrees with its tree (Facts 11.1 and 11.2, in the direction used in the c8 chain); (ii) nesting P_{j′,u′} ⊆ P_{j,trunc(j,u′)}; (iii) for an internal non-root node, the sum of the sizes of its child P sets is at most twice the size of its parent P set; (iv) the root-level sum is at most 2|Q|; (v) every point in every P set is in the middle layer (the premise of Fact 16). All pass.
- **E12 (the third condition of “good” follows automatically for Dyes):** The E7 filter already requires ρ to be constant on each leaf's P_u; all yes-side samples satisfy this, directly because h_u is a constant function.

## How to read these checks

- These examples check that predicates behave as expected; they are not evidence of Lean compilation. Compilation of all three Lean tiers is verified on the platform (Lean/Lake are unavailable locally).
- Small parameters exercise the combinatorial mechanisms only. Constants and rates in asymptotic claims (Ω(1), o(1), o(n)) are checked item by item in `concept-ledger`.
