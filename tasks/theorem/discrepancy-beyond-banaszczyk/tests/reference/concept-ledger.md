## 3. Statement-level deviations (itemized, with reasons)

1. **Existential form.** The main theorem and all high-probability conclusions are used only to establish the existence of a good coloring. The paper’s “polynomial-time algorithm” statements (Theorems 3.1 and 5.1 say “there is a polynomial time algorithm”) and Theorem 2.2’s “such a PSD matrix U can be computed by solving a semidefinite program” are not included in the statements. c6 uses probability at least 1 − 1/√n (any fixed inverse polynomial works for the paper’s “with high probability”; 1/√n suffices for the assembly).
2. **Finite Rademacher sample space.** The paper writes the walk in continuous time (dt tends to 0 and O(dt^{3/2}) is ignored); its rigorous version is a finite-step random walk. The package uses T steps and the uniform distribution on {±1}^{T×n}, with conditional expectations along the coordinate filtration. The paper’s E_t[·] (conditioning on all randomness up to time t) agrees with `condExpU t` (conditioning on coordinates in earlier steps): the walk is a deterministic function of these coordinates.
3. **Slack and existential constants are packaged together.** Three places “ignore lower-order terms”: (a) Lemma 3.6, where expanding E[(dY)²] produces O(dt^{3/2}) cross terms; (b) Theorem 3.7, the poly(n)(dt)^{3/2} term in footnote 13; (c) Lemma A.3, the O(dt^{3/2}) term in the expansion of E[(dZ)²]. They are handled uniformly by giving the conditional pairwise-independence predicate additive slack ε (`CondPWSlackU`), expressing the small quantity in c4 as `∃ M₀ ε₀`, in c5 as `∀ ε > 0, ∃ T₀, T ≥ T₀ ⟹ …`, and in c3 as `∃ M₀ C`. These constants depend only on scalar parameters, not on the process itself, to prevent vacuous truth. The term-by-term check is that the cross term is O(√dt) relative to the main term (see the calculation for the c5 step in Section 4); for sufficiently large T it is absorbed into ε.
4. **FAIL uses generator counts.** Paper Step 1 tests dim(W_t) > n_t/3; the package tests whether 1 + number of large rows + number of dangerous level-L rows > n_t/3. Since dimension is at most the number of generators, the count-based condition has the correct implication: count ≤ n_t/3 ⟹ dimension ≤ n_t/3, so c1 applies. The event in c6 implies that the count-based test does not trigger (the same calculation as the opening paragraph of “Proof of Theorem 1.3” in §5.2: n_t/10 + n_t/10 + 1 ≤ n_t/3).
5. **The main theorem uses the {0,±1} form** (the statement of Theorem 5.1), stronger than Theorem 1.3’s set-system form with {0,1}. Logarithms use the natural base (`Real.log`); the paper does not specify a base, and the difference is absorbed in constant c. Boundary: n ≥ 2 is included in the statement (needed for log n > 0; the paper assumes n sufficiently large at the start of Theorem 3.7).
6. **Energy G sums over all coordinates** (the form in §3.2.1, Formula (18)), while §5.1 sums only over alive coordinates. For a dead coordinate j, |x_t(j)| > 1 − 1/(2n), so 1 − x_t(j)² ≤ 1/n; the difference between the two forms is O(1)·β_ℓ and is absorbed by b_ℓ. The package uses the all-coordinate form, which is compatible with both uses.
7. **Tiny row means size ≤ µ** (§5.1 says “sizes at most µ”; §3.1 says “less than µ”). The ≤ form matches the interval chosen in §5.

## 4. Step-by-step check of the main theorem assembly (the c7 chain)

The derivation assembles the packaged main theorem (c7) from c1+c3+c6, following “Proof of Theorem 1.3 for k = Ω(log² n)” in §5.2 and expanding intermediate steps omitted in the paper. Each step identifies its basis; steps marked ⚠ are places where the paper itself gives only a sketch, which is stated explicitly.

1. **Constants and the trivial range.** Let C_th be the threshold from c6. Also require C_th large enough that (n/ln n)² < C_th for every 2 ≤ n ≤ e^{10}; the left side has a maximum on this bounded interval, so such a choice exists. This ensures the c4 premise λB = 10 ≤ log n for every instance where c6 needs it: combining C_th(log n)² ≤ k and k ≤ n² gives C_th ≤ (n/ln n)², hence n > e^{10}. This resolves the degenerate small-range issue found by self-check 6.5, item 2. Set c := C_th and C_b := C_th (the parameter-table C); the final C := 3C_b·∑_{ℓ≥0}5^{-ℓ} + the remainder constant (fixed in steps 6 and 7). Preprocess m by deleting all-zero rows (which does not change disc). Every remaining row has at least one nonzero entry; since the total number of nonzeros is at most nk, **m ≤ nk** (the paper does not spell out this step, but its high-probability union bound over all rows needs it). If k > n², then for any coloring each row satisfies |⟨a_i,x⟩| ≤ n < C√k (C ≥ 1), so the result is trivial. Henceforth assume k ≤ n²; then m ≤ n³ and the logarithmic union bound applies.
2. **Parameter table** (§5.1): choose T sufficiently large (at least the thresholds corresponding to M₀ for c3/c4 and T₀(ε₀) for c5, and T ≤ n^8 to satisfy hT in c3; set c := 8); b_ℓ = C_b·2^ℓ√k_ℓ, k_ℓ = k/100^ℓ, β_ℓ = b_ℓ/(2^ℓ·10k_ℓ), µ = b₀²/log n (from k ≥ c(log n)², b₀ ≥ C_b log n·(constant), so µ = b₀²/log n ≥ b₀, agreeing with the paper’s “µ = max(b₀, b₀²/log n) = b₀²/log n”); choose L by 100^L ≤ 10k/µ < 100^{L+1} (the paper sets L := log_{100}(10k/µ); the rounding difference is absorbed); η = 1/6.
3. **Constructing the increment law (where c1 is used).** At every non-FAIL history, take h := n_t (the number of alive coordinates), W := span{large rows a_i, level-L dangerous rows eRow_L, x_t}, restricted to alive coordinates; its dimension is at most n_t/10 + n_t/10 + 1 ≤ n_t/3 =: δh (by the c6 event). Set q := L+1, E_ℓ := the eRow of medium level-ℓ rows restricted to alive coordinates (R_ℓ := |M^(ℓ)| rows; if |M^(ℓ)| = 0, add a zero row so c1’s R_s ≥ 1 is satisfied, making that level’s affine constraint vacuous); κ := 1/6, η := 1/6, η_ℓ := 1/(6·2^ℓ). Then δ + κ + η + Σ_ℓ η_ℓ ≤ 1/3 + 1/6 + 1/6 + 1/3 = 1 (numerically checked in small example E9). c1 gives U. Take its spectral decomposition U = QΛQᵀ (a positive semidefinite matrix has a spectral decomposition, available in mathlib), and set v := (Tr U)^{-1/2} QΛ^{1/2} r, where r is a fresh Rademacher vector (Tr U ≥ κh > 0 ensures division is valid). Then E[v] = 0; ‖v‖ = 1 (since rᵀΛr = Tr Λ); supp v is within the alive coordinates (W contains the unit vectors for dead coordinates, so U is zero there and likewise v); v is orthogonal to every vector in W (⟨wwᵀ,U⟩ = 0 and U is positive semidefinite imply Uw = 0, hence wᵀQΛ^{1/2} = 0); and covariance E[vvᵀ] = U/Tr U, so condition (iv) gives spectral independence and (v) gives affine spectral independence (the factor (R_ℓ/h)/η_ℓ = (2^ℓ/η)(|M^(ℓ)|/n_t), exactly as in `StepLawProp`). On a FAIL history set v := 0. This satisfies every clause of `StepLawProp`.
4. **The c6 event occurs:** probU ≥ 1 − 1/√n > 0 (since n ≥ 2). On this event, for each column and level at most k_ℓ rows reach that level, and at most k_L/100 rows are dangerous at level L.
5. **No FAIL.** As in the same paragraph of §5.2, the total number of large rows is at most Σ_ℓ n_t k_ℓ/(2^ℓ·10k_ℓ) = Σ_ℓ n_t/(10·2^ℓ) ≤ n_t/10 (each large row has at least 2^ℓ·10k_ℓ nonzero positions among alive coordinates, and each column has at most k_ℓ rows at level ℓ, so the total number of nonzero positions is at most n_t k_ℓ). The number of dangerous level-L rows is at most n_t k_L/(100µ) ≤ n_t/10 (each dangerous row has size at least µ; the last inequality follows from 10k/µ < 100^{L+1}; small examples E8/E8b numerically checked the parameter arithmetic). Including the single vector x_t, the generator count is at most n_t/10 + n_t/10 + 1 ≤ n_t/3 (for n_t > 10), so `FailEvent` never triggers on this event.
6. **Row-by-row discrepancy accounting** (the final paragraph of §5.2): while row i is at level ℓ, Y^(ℓ) < 2b_ℓ (otherwise it would have upgraded; the overshoot at the upgrade time is at most O(√dt) and is absorbed), and Y^(ℓ) ≥ the change in ⟨a_i, x⟩ − 0 while β_ℓG ≤ β_ℓ·(size+1) ≤ b_ℓ + o(1) (since G ≤ size + 1: alive coordinates contribute at most size, dead coordinates contribute at most number of dead coordinates·(1/n) ≤ 1). Thus the discrepancy accumulated while at level ℓ is at most 3b_ℓ. Summing over ℓ gives Σ_ℓ 3C_b·2^ℓ·√(k/100^ℓ) = 3C_b√k·Σ_ℓ 5^{-ℓ} = O(√k). After a row becomes tiny: if its size is at most µ, c3 (take y to be the walk itself, σ² = 6 from spectral independence, and ‖a_i‖² ≤ µ + 1) bounds the remaining discrepancy by O(√((µ+1) log n)) = O(b₀), since µ = b₀²/log n. Apply a union bound over all m ≤ n³ rows: each row’s failure probability from c3 is n^{-(c+1)} = n^{-9}, so m·n^{-9} ≤ n^{-6}; combined with c6’s 1/√n failure probability, the success probability is still positive. (The failure-probability exponent in c3 is fixed by c = 8; it suffices, whereas the paper only writes “with high probability”.)
7. **Final rounding** (the standard method from §2.1): at the end x_T ∈ [−1,1]ⁿ; dead coordinates satisfy |x(j)| ≥ 1 − 1/(2n), and at most 10 coordinates are alive. Round each coordinate to a sign to obtain ±1 coloring x̃. The change in any row’s discrepancy is at most Σ_j |a_ij|·|x̃_j − x_T(j)| ≤ (n−10)·(1/n) + 10·2 ≤ 21, which is absorbed into C (in the stated range, C√k ≥ C·√c·log n ≥ 21). **From one-sided to two-sided:** the argument above bounds ⟨a_i,x⟩ on one side. Apply the same theorem to the stacked matrix [A; −A] (which retains column sparsity and {0,±1} entries) to obtain a two-sided bound |⟨a_i,x⟩|. The paper explicitly states this reduction in its notation paragraph in §2: “it suffices to upper bound the one-sided discrepancy … by appending the rows −a_i”.
8. **Probabilistic method:** positive probability of the good event implies that there is an ω whose final coloring meets the bound, hence `discLe A (C√k)`.

**⚠ Two places where the paper itself gives only a sketch and the package records this explicitly:**
- (The extension trick in footnote 11 / §5.2.) Y^(ℓ) is extended as the constant b_ℓ on large and unreached rows, and as −∞ on tiny rows; transition between classes can have a discontinuous downward jump. The c6 proof uses a freezing correction for the restricted process of each column and level (when the invariant fails, set increments to zero; zero increments trivially satisfy pairwise independence), which agrees with the original process on the invariant event. A downward jump only makes W_t smaller, so the direction of c4’s drift inequality is preserved. This route has been worked through step by step according to the paper’s logic, but has not been machine-checked step by step (L2 has no standard solution; its level of formal detail matches the paper).
- (Induction on ℓ and the high-probability union in c6.) At induction step ℓ, use the invariant event at level ℓ (probability loss at each level is at most on the order of 1/n, and the union over L+1 levels and n columns is absorbed). This follows the paper’s wording, “We prove the lemma by induction on the level ℓ”; the combination details are as above.

## 5. Premise-by-premise check of each checkpoint (bciks20 discipline: check every premise, quantifier, and boundary)
